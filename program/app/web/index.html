2. 突合せキー

スケジュールの項目と台帳の列の組を指定します。複数の組を指定すると、すべての組が一致した行を結合します。 値は全角／半角・大文字／小文字・空白の違いをそろえ、数値は数値として比較します（0.300 と 0.3 は一致）。

2. 点検行の判定

ロットNo または 用途名にこの文字を含み、板厚・幅のデータがある行を「点検」として扱います（1行に1語）。点検行は製造件数・ロット数・台帳突合せから除きます。
